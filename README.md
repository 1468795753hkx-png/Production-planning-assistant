# 制造计划助手（AI-Assisted Production & Procurement Planning）

> 面向订单的制造业计划与决策支持工具 —— 输入客户订单（或启用需求预测）后，自动完成 **生产计划 → BOM 展开 → MRP 物料净需求运算 → 采购计划 → 采购订单分级**，并在需求、供应与产能不确定下给出**情景对比、成本优化与人机协同（Auto/人工）建议**。

一个可直接用浏览器打开的单页演示工具：`index.html`（无第三方依赖，纯 HTML + JS）。

---

## 一、项目定位 / 一句话介绍

> 输入一批客户订单，系统自动拆解 BOM、算物料净需求、生成生产计划和采购建议，并对产能瓶颈和供应商加急风险提前预警；还能一键切换情景、给出容量均衡下的成本优化方案。

它复现的是供应链计划岗位上最核心的日常工作：**在交期、产能、物料三者之间做权衡决策。**

---

## 二、背景与动机

专业为**物流与供应链管理**。在商战/ERP 沙盘中担任**生产经理**：中标后按订单需求制定采购计划与生产计划，体会到"一张单牵扯到物料、产能与交期"的权衡。本项目把这个业务经验模型化、可视化、AI 化，作为 AI 应用能力与供应链计划能力的作品集证据。

---

## 三、解决了什么业务痛点

计划员最耗时、也最容易出错的环节是：把订单变成可执行的物料与生产计划，并提前识别风险。本工具把这一过程**自动化、可视化、可对比**：

- 订单 → 生产计划（考虑安全库存与产能）
- 生产计划 → BOM → MRP 物料净需求（考虑库存 / 在途 / 安全库存 / 提前期）
- 输出采购建议与**风险预警**（产能瓶颈、供应提前期加急）
- 支持**多情景切换**与**成本优化**，支撑计划决策而非只有单一答案

## 四、功能模块

| 模块 | 说明 |
| --- | --- |
| 需求预测 | 基于近 12 周历史销量，用轻量时间序列（Holt 线性趋势/线性回归）预测未来 4 周，含留出法 MAPE；可切换"用预测需求驱动计划" |
| 需求与生产计划 | 按周展示市场需求 vs 计划产量 vs 周产能，超产能周标红 |
| 成品生产计划明细 | 各产品每周应生产数量（保障安全库存前提下） |
| 物料需求计划 MRP | 各物料每周毛需求、现有库存、安全库存、净需求、采购单数 |
| 采购计划汇总 | 按物料给出供应商、提前期、建议采购量、下单周→到货周、采购成本 |
| 采购订单分级（Auto/人工） | 把采购建议落地为采购订单，按"低风险 AI 自动放单 / 高风险人工审批"分级（提前期越界、关键件、金额阈值可调） |
| 风险预警 | 自动识别产能瓶颈与供应提前期加急风险 |
| 情景分析 | 需求 +10% / 供应提前期 +30% / 产能 -15% / 组合，双方案对比 |
| 成本优化建议 | 容量均衡 + 成本最小化（按需投产），给出前后成本拆解与节省 |

## 六、核心方法

**MRP 净需求运算**

```
净需求 = 毛需求（Σ 各成品产量 × BOM 用量）
       − 现有库存 − 在途到货 + 安全库存
采购下单周 = 需求周 − 提前期（换算为周，不足则标记加急）
```

**成本优化模型**

```
总成本 = 生产成本 + 持有成本 + 短缺成本 + 采购成本 + 超产能加班成本
优化的做法：按需投产（lot-for-lot，最小化在库）+ 容量均衡（把过载周的产量
前移到有空闲产能的周，优先移动持有成本低的成品），在周产能硬约束下最小化总成本。
```

**目标模型 vs 当前实现（如实区分，避免口径混淆）**

- **当前实现**：`lot-for-lot` 按需投产 ＋ 容量均衡前移的**启发式**。页面实际运行的是它（无求解器依赖），目标是产能可行、按时交付并降低总成本；不保证全局最优。
- **目标模型（Roadmap）**：多周期容量受限批量排产 **CSPL/CLSP（MILP）**——含换产固定费、多级 BOM 提前期反冲、服务水平安全库存下界，可对接求解器求理论最优。
- **当前不声称已实现 MILP / Fix-and-Relax**；如需对齐，走"路线 B"用 PuLP/SCIP 实现并将离线条解 cache 到页面。
- 完整（修正版）数学定义见 [《CLSP 数学规划白皮书 · 修正版》](CLSP-白皮书-修正版.md)。

**需求预测（轻量时间序列）**

```
Holt 线性趋势 / 线性回归（最小二乘）：y = a + b·t
留出法验证：前 10 周训练、后 2 周测试 → MAPE
预测未来 4 周，可“替代既有订单”驱动 MRP / 优化 / 采购。
```

> 当前为轻量预测模型（确定性趋势），未含季节性/置信区间；升级见后续规划。

**采购订单分级策略（Auto vs 人工）**

```
低风险（不超提前期、非关键件、金额低于阈值）→ AI 自动放单
命中 提前期越界 / 关键长交期件 / 金额达到阈值 → 升级人工审批（阈值可调）
```

**换产边界（技术诚实说明）**

> 目标模型含换产固定费 S<sub>i</sub> 与工时 s<sub>i</sub>；当前启发式未计换产。盲目前移可能造成批次碎片化，故"优化降本"结论不包含换产代价——这是向 CLSP/MIP 演进的核心动机（MPS 层聚合换产亦为 SAP ECC 常见做法）。

## 七、示例结果（默认参数，4 周 / 产能 2,900）

- 成品订单总量 ≈ 10,800 件；计划总产量 ≈ 10,490 件
- 物料净需求：M001 ≈ 8,980 / M002 ≈ 0 / M003 ≈ 20,490 / M004 ≈ 1,600 件（合计 ≈ 31,070）
- 建议采购成本 ≈ €237,620
- 周产能默认 2,900：基准无产能瓶颈；切"产能 -15%"情景（2,465）才出现瓶颈，提前期越界示例保留 M004（21 天）第 1/2/3 周最早到货周均为 W4，分别晚 3 / 2 / 1 周
- 成本优化：€749,676 → €730,120（节省约 €19,556；基准无加班费，节省主要来自按需投产降低生产与持有成本）
- 采购订单分级（默认自动放单上限 €30,000）：AI 自动放单 4 笔 / 人工审批 6 笔，自动放单金额占比约 24%（M003 大额单与 M004 关键件升级人工）
- 勾选顶部"使用预测需求"后切换为预测驱动：成品订单 12,060、采购成本 €443,331（体现"需求上升 → 主动加大备货"）

> 提示：调整顶部"需求调整系数 / 周产能 / 情景分析"即可实时看计划与优化如何变化。

## 九、职业叙事（供面试使用）

1. **定位**：我在沙盘里做生产计划，这个工具把我的经验模型化。
2. **价值**：它不只是一个算数工具，而是帮计划员**在交期、产能、物料、成本之间做权衡决策**。
3. **亮点**：需求一动，立刻看到哪几周产能紧张、哪些物料要加急；还能一键对比情景、给出成本更低的可行排产。
4. **人机协同**：采购订单按风险分级——低风险标准单由 AI 自动放单、关键/高风险单（提前期越界、大额、长交期件）升级人工审批，体现"AI 做例行执行、人做商业判断"的分工。
5. **诚实**：数据为模拟制造参数，模型可扩展接入真实数据与 MILP。
