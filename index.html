目标函数（总成本最小 · 目标模型：CLSP / MILP）
  min Z = Σt Σi ( Si·Yit + ci·Xit + hi·Iit ) + Σt cOTt·Ot

核心约束（修正版）
· 物流守恒（产出侧提前）：Iit = Ii,t-1 + Xi,t-Li − dit − Σk∈Parents(i) γki·Xk,t
· 产能：Σi ( pi·Xit + si·Yit ) ≤ Ct + Ot，且 0 ≤ Ot ≤ COTt
· 批量/固定费关联：Xit ≤ Mit·Yit（M 匹配产能上限与总需求，总需求含下游 BOM 反推量）
· 安全库存下界：Iit ≥ SSit

目标模型 vs 当前实现（如实区分）
· 目标模型：上述 MILP（含换产固定费、多级提前期反冲、服务水平安全库存），可对接求解器求理论最优——为升级路线（路 B）。
· 当前实现：本页面实际运行 lot-for-lot 按需投产 ＋ 容量均衡前移 的启发式（无求解器），保证产能可行、按时交付并降低总成本，但不承诺全局最优。
· 当前未实现 MILP / Fix-and-Relax；如需对齐走路线 B。完整定义见《CLSP 数学规划白皮书 · 修正版》。

技术边界 · 关于换产（Setup）
· 目标模型含换产固定费 Si 与换产工时 si（上式 Yit 项）。
· 当前启发式暂未将换产纳入决策：容量均衡按产量件数前移，不额外计换产费/换产工时，也不做批量合并。
· 影响：多产品共线且换产成本高时，盲目前移可能导致小批量碎片化（换产频次上升），故当前“优化降本”结论不包含换产代价；这正是向路线 B（CLSP / MIP，0-1 变量 Yit）演进的核心动机。将换产聚合到工时定额、在 MPS/中程计划层忽略细节换产，也是 SAP ECC 等工业软件的标准做法。
